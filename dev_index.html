Building the Future with Modern Web Tech

Join us for an intensive, hands-on event featuring expert tracks and live challenges.

Workshop Overview

This event is designed for developers, designers, and tech enthusiasts looking to explore the cutting edge of web technology. We bring together industry leaders to share insights, review core architectures, and host two exciting live competitions.

  • Comprehensive deep-dives into modern web architecture
  • Multiple concurrent tracks for frontend and security frameworks
  • Open panels and networking with senior engineers

Target Audience

Open to all skill levels! Whether you are a student, a hobbyist, or an experienced engineer looking to branch out.

Core Focus Areas

Explore the specific key concepts that will be broken down in detail during the instruction blocks.

Advanced UI Layouts

Mastering fluid styling engines, advanced grid structures, container queries, and fully adaptive component frameworks.

Performance Optimization

Tackling bundle size rendering bottlenecks, server-side caching mechanics, and localized global deployment optimizations.

Web Application Security

Understanding modern web standards for token authorizations, state protections, and handling dynamic application vulnerabilities.

Live Workshop Competitions

Put your skills to the test. This year features two distinct engineering tracks running side-by-side.

TRACK A 3 Hours

The UI/UX Speed Build

Teams or individuals must completely transform a plain textual application layout into a fully responsive, pixel-perfect interactive dashboard based on a hidden design layout file revealed at the starting bell.

  • Prize: $500 Tech Gift Card
  • Team Size: Solo or Pairs
TRACK B 3 Hours

The Architecture & Security Hack

A fast-paced structural competition focused on performance engineering. Teams will fix a broken, intentionally unoptimized application architecture to pass complex security scans and payload speed metrics.

  • Prize: Custom Mechanical Keyboards
  • Team Size: Up to 4 Members
